# MAP-3 — Support de validation visuelle

La tâche technique est terminée ; cette page sert à la revue du propriétaire. Elle ne ferme pas MAP-3 sans accord explicite.

## Direction à valider

- style principalement noir et blanc ;
- inspiration des applications modernes de mobilité ;
- marqueurs et sélection immédiatement visibles ;
- trajet lisible sur le fond cartographique ;
- panneaux et commandes discrets ;
- bonne lecture sur téléphone ;
- erreurs fournisseur et attribution cartographique toujours visibles.
