# Lot b-carte — MAP-INTERACTION, MAP-3, carte sombre (DESIGN-2)

## Livré
- Plan Menthe sombre (`menthe-style.ts`, thème lu sur `<html data-theme>` via `use-map-theme.ts`, rechargement du fond au changement de thème), CSS `map-theme.css`, palette sombre des marqueurs, trajets, livreurs, navigation. Aucun nouveau fournisseur.
- Carte unifiée du tableau de bord (`dashboard-map-panel.tsx`) : onglets Livreurs / Livraisons (flèches, Début, Fin), marqueurs sélectionnables (clic, tactile, Entrée/Espace), fiche flottante (lien fiche livreur / livraison), liste repliable accessible, légende, Échap.
- Statuts : couleur mesurée (3:1) + forme (triangle, anneau, carré, disque) + libellé.
- États : chargement, aucun livreur, pas de position, signal perdu (position périmée), aucune mission, adresse non localisée, erreur (bandeau + Réessayer), fond indisponible (existant).
- Anciennes dispositions à deux cartes : une seule affichée (`mergeMapWidgets`).
- Tests : `tests/b-carte-map.test.ts` + tests existants alignés. `npm run check` vert.

## Décisions
- Types de widget `map-drivers`/`map-deliveries` conservés (dispositions enregistrées) ; les deux ouvrent la carte unifiée. Alternative écartée : migration des dispositions.
- Jetons manquants (lot A) définis localement dans `map-theme.css` et `map-visual-theme.ts`.
- Aucune précision GPS inventée : affichée seulement si relevée et en direct.
